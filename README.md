# جزوه‌های باکتری‌شناسی

راهنماهای مطالعهٔ فارسی برای هشت جزوهٔ باکتری‌شناسی، شامل ۹۰ درس با بیان فارسی روان، پرسش و پاسخ تشریحی، فلش‌کارت و مرور سریع.

[مشاهدهٔ وب‌سایت](https://ali-hazrati.github.io/bacteriology-study-guides/)

برای استفاده، پروژه را دانلود و فایل [صفحهٔ اصلی](study-guides/index.html) را در مرورگر باز کنید. نصب برنامه یا اتصال به اینترنت لازم نیست. فایل‌های PDF را در پوشهٔ اصلی پروژه نگه دارید تا ارجاع‌های هر راهنما باز شوند.

## فایل‌های پروژه

- `study-guides/index.html`: فهرست و دسترسی به همهٔ راهنماها.
- `study-guides/استاد … .html`: راهنمای هر استاد.
- `استاد … .pdf`: جزوه‌های اصلی و مقصد ارجاع‌ها.
- `study-guides/_work/`: منابع ساخت راهنماها، قلم و مجوز آن، و گزارش پوشش مطالب.

تصاویر موقت استخراج صفحات، پیش‌نمایش‌ها و حافظهٔ موقت پایتون در مخزن قرار نمی‌گیرند.

این راهنماها برای مطالعهٔ درسی تهیه شده‌اند. دامنهٔ پوشش و توضیحات هر جزوه در راهنمای همان فایل آمده است.

## ساخت دوبارهٔ راهنماها

پس از ویرایش محتوای هر درس، فایل سازندهٔ همان راهنما را با پایتون ۳ از پوشهٔ اصلی پروژه اجرا کنید؛ برای مثال:

```powershell
python study-guides/_work/build_guide.py
python study-guides/_work/build_hakemi.py
```

نام فایل سازندهٔ هر استاد در پوشهٔ `_work` مشخص است؛ `build_guide.py` راهنمای استاد حاجی خانی را می‌سازد. متن پرسش‌ها و پاسخ‌ها مبنای ساخت فلش‌کارت‌ها هم هست؛ بنابراین تغییر پاسخ در فایل سازنده، هر دو بخش را به‌روز می‌کند. برای ساخت این فایل‌های مستقل، نصب کتابخانهٔ اضافی لازم نیست.

ارجاع‌های هر درس به جزوهٔ اصلی حفظ شده‌اند. منابعی که برای توضیح‌های تکمیلی استفاده شده‌اند، در زبانهٔ «منبع» همان راهنما در دسترس‌اند.
